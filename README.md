# Dmitry Kurochkin

.NET developer. Minsk, Belarus.

Author of **[Pure](https://github.com/kudima03/Pure)** — 75 immutable, composable, AOT-compatible .NET packages, from primitives up through hash codes, collections, relational schema, charts and diagrams. One repository per package, multi-targeted `net7.0`–`net10.0`, each gated on 98% coverage and a 99% Stryker mutation score.

Author of **[PureQL](https://github.com/kudima03/PureQL-Specification)** — a JSON-based declarative query language for relational data. Queries are plain JSON validated against a JSON Schema, so they can be generated, serialized and transmitted without a parser.
